# Changelog

Формат — Keep a Changelog. Секция версии становится release notes в окне
обновления Sparkle: `scripts/release.sh` переносит её в `<description>`
аппкаста. Без секции для выпускаемой версии релиз не собирается.

## [2.1.1] — 2026-10-06

### Исправлено

- Хоткей отмены конвертации слова (⌥⇧Space по умолчанию) снова работает при
  включённом автоисправлении — раньше вместо отмены в текст вставлялся
  неразрывный пробел.
- Удержание хоткея конвертации больше не переворачивает слово туда-обратно:
  автоповтор зажатой клавиши игнорируется, одно нажатие — один переворот.
- Конвертация по хоткею срабатывает мгновенно при нажатии, не дожидаясь
  отпускания клавиш.
